Toujours relire les fichiers de code pertinents avant de répondre à une question sur le code, même si je les ai déjà lus plus tôt dans la conversation.

**Why:** L'utilisateur veut que les réponses soient basées sur une lecture fraîche du code, pas sur ce qui est en mémoire de contexte.

**How to apply:** Avant chaque réponse technique sur le code, utiliser Read sur les fichiers concernés.
